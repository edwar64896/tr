Issue a Pass

Talyllyn Railway Archive · recovery tool

You shouldn't normally need this page. Passes are issued from /admin.html on the archive itself. Use this only when that isn't possible — because an administrator pass has expired, or because you're setting the archive up for the first time.

Signing key

The key is in the gate function: AWS console → CloudFront → Functions → tr-archive-auth → Build, on the line beginning var SECRET. Copy what's between the quotes.

This page does no networking whatsoever — the key is used in your browser and goes nowhere. You can check that yourself: it's a single file with no fetch in it, and it works with the network unplugged.
