Talyllyn Railway Archive · admin tool

1 Choose the MODES export

When new artifacts are added, export the collection from MODES as XML and drop the file here. Everything runs in your browser — nothing is uploaded yet.

3 Download the catalogue

This produces catalogue.json — the single data file the website reads.

4 Publish it

Four steps — the same folder-and-sync routine you use for scans:

  1. Drop it in the archive folder. Move the catalogue.json you just downloaded into your local “Archive Objects” folder — the one your scans and PDFs live in — replacing the old catalogue.json. It must sit at the top of that folder, next to the image files (not in a sub-folder).
  2. Sync to S3. Run GoodSync as usual. Check that catalogue.json appears in the changes and the sync finishes.
  3. Clear the cache. Open the CloudFront console → your distribution → Invalidations → Create invalidation → type /catalogue.json → Create invalidation. Wait until it says Completed (about a minute).
  4. Check. Open the website and refresh — the new records are live.

New scans or PDFs just go in the same “Archive Objects” folder with their exact MODES filenames (e.g. Z-DDJ-1-51a.jpeg, z-ddj-1-27.pdf) and ride along on the same GoodSync. Only catalogue.json needs the cache-clearing step — new files don't.

Access passes

Issue a pass

The archive is private. Create a pass here, then email the link to the person — opening it lets them in for as long as the pass lasts, with nothing to type. Passes expire on their own; there is no list to tidy up afterwards.

The name is only recorded inside the pass so you can tell later who it was issued to. An administrator pass also opens this page — only issue one to someone who should be able to update the catalogue and issue passes of their own.

Write the email

Worth knowing. Anyone who has the link can use it — if it's forwarded on, it works for whoever receives it. That's why the shorter passes exist; prefer a day pass for a one-off enquiry. To cut off every outstanding pass at once, a new signing key is needed — see “If a pass needs cancelling” in deploy/INSTALL-AUTH.md.
