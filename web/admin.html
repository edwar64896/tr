Update the Catalogue

Talyllyn Railway Archive · admin tool

1 Choose the MODES export

When new artifacts are added, export the collection from MODES as XML and drop the file here. Everything runs in your browser — nothing is uploaded yet.

2 Review

Extracted from the export (folder paths stripped from every image/media filename):

3 Download the catalogue

This produces catalogue.json — the single data file the website reads.

4 Publish it

Upload the downloaded catalogue.json to the archive S3 bucket and refresh the CloudFront cache. The simplest way is one script from the project:

./deploy/publish-catalogue.sh ~/Downloads/catalogue.json

Prefer to do it by hand? Two commands:

aws s3 cp catalogue.json s3://trarchive-766743414531-eu-north-1-an/catalogue.json
aws cloudfront create-invalidation --distribution-id <your-dist-id> --paths /catalogue.json

The website (served at dmfmj7c4s21wr.cloudfront.net) shows the new data on the next refresh.

  1. Scanned images / PDFs go in the same bucket, named exactly as in MODES (e.g. Z-DDJ-1-51a.jpeg) — the site builds each link from the filename. They're new files, so they need no cache invalidation.
  2. No repo / AWS CLI handy? Hand the downloaded catalogue.json to whoever manages the site and they'll run the publish step.
